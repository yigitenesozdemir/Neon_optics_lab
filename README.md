# NeonOptics Lab

Bilgisayarlı görü (computer vision) teknolojileri kullanılarak geliştirilen, el hareketleriyle kontrol edilebilen sanal bir optik ve fizik laboratuvarı simülasyonu. 

**Mevcut Durum (1. Hafta):**
- Proje sanal ortam (venv) mimarisi kuruldu.
- OpenCV ile siyah tuval (laboratuvar ortamı) oluşturuldu.
- MediaPipe entegrasyonu ile el iskeleti takibi (hand tracking) sağlandı.
